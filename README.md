# Student Dropout Prediction Using Machine Learning

## Project Overview
This project focuses on predicting student dropout using machine learning. The aim is to identify students who may be at risk of leaving their studies by analyzing student-related data and comparing different classification models.

## Dataset
The project uses a student dropout dataset containing information used to train and evaluate the prediction models.

## Machine Learning Models
Four classification models were implemented and compared:

- Logistic Regression
- Support Vector Machine (SVM)
- Naive Bayes
- Multilayer Perceptron (MLP)

## Methodology
The project involved several stages:

1. Data exploration and preprocessing.
2. Preparing the dataset for model training.
3. Training different machine learning classifiers.
4. Evaluating model performance.
5. Comparing the results to identify the best-performing approach.

## Model Evaluation
The models were evaluated using classification metrics, including:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Tools and Technologies
- Python
- Google Colab
- Pandas and NumPy
- Scikit-learn
- Matplotlib

## Project Purpose
The project demonstrates how machine learning can support educational institutions in identifying students at risk of dropping out, potentially helping them provide earlier academic support.
